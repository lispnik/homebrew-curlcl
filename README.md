# Lispnik Curlcl

## How do I install these formulae?

`brew install lispnik/curlcl/<formula>`

Or `brew tap lispnik/curlcl` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lispnik/curlcl"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
